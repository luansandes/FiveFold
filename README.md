# Fivefold Web

Fivefold Web is an auditable agentic organisation for Dublin website prospecting. Exactly
five specialised AI agents build on one another's work:

1. Researcher identifies and qualifies a live opportunity.
2. Designer converts the evidence into an experience specification.
3. Maker produces a safe, responsive landing-page artefact.
4. Communicator prepares human-operated outreach materials.
5. Manager checks the complete chain, unit economics, and next human action.

The application has no offline, seeded, or simulated execution mode. Discovery always
uses Google Places and all five agent stages always use OpenAI. Missing live credentials
prevent the application from starting.

## Setup

```powershell
python -m pip install -e ".[dev]"
Copy-Item .env.example .env.local
python scripts/hash_password.py
python scripts/migrate.py
uvicorn api.index:app --reload
```

Fill `.env.local` before starting. Never commit it.

| Name | Purpose |
| --- | --- |
| `DATABASE_URL` | SQLAlchemy database URL; use pooled Neon Postgres when deployed |
| `OPENAI_API_KEY` | Required for all five agent stages |
| `OPENAI_MODEL` | Model used by the OpenAI Agents SDK |
| `GOOGLE_MAPS_API_KEY` | Required for Google Places discovery |
| `ADMIN_PASSWORD_HASH` | PBKDF2 hash generated by `scripts/hash_password.py` |
| `SESSION_SECRET` | Signs admin sessions and CSRF tokens |
| `CRON_SECRET` | Authenticates the worker cron |
| `PREVIEW_SIGNING_SECRET` | Reserved for preview-key rotation |
| `BASE_URL` | Canonical URL used in communication drafts |

## Runtime architecture

- FastAPI and Jinja templates provide the dashboard and JSON API.
- Google Places Text Search discovers businesses through a minimal field mask. Raw Places
  responses and reviews are not persisted.
- The OpenAI Agents SDK runs the five agents with distinct prompts and typed outputs.
- A SQLAlchemy-backed queue provides idempotent jobs, bounded retries, row-locked claims,
  and resumability.
- Generated previews use 30-day revocable bearer links, `noindex`, restrictive CSP,
  disabled enquiry actions, and an independent-concept disclosure.

## Safe operating boundary

- A human must independently verify contact details and manually send every message.
- Agents cannot send mail, post to social platforms, buy domains, or publish an official
  client website.
- Testimonials remain labelled placeholders until supplied or approved by the business.
- Domain availability and prices are time-stamped estimates; no reservation occurs.
- External pages are untrusted data and never treated as agent instructions.
- The Manager reports early-cancellation risk and cohort margin without guaranteeing
  per-customer profit.

## Vercel and Neon

```powershell
vercel whoami
vercel link
vercel integration add neon
vercel env pull .env.local --yes
python scripts/migrate.py
vercel dev
```

Configure every required environment value for development, preview, and production.
`vercel.json` routes all public paths through FastAPI and defines a daily authenticated
worker cron. The Hobby-compatible pilot processes one agent handoff per invocation within
the 60-second Python function limit; the dashboard can advance queued work immediately.
