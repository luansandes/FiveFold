# Fivefold Web

Fivefold Web is a demonstrable agentic organisation for a fictional Dublin website
service. Exactly five specialised AI agents build on one another's work:

1. Researcher — identifies and qualifies the opportunity.
2. Designer — converts the evidence into a bespoke experience specification.
3. Maker — produces a safe, responsive landing-page artefact.
4. Communicator — prepares human-operated outreach materials.
5. Manager — checks the complete chain, unit economics, and next human action.

The workflow engine is deterministic infrastructure, not a sixth agent. It records every
stage, artefact version, handoff, correction, retry, and human action in Postgres. There
are deliberately no email-sending or domain-purchasing capabilities.

## Demonstration

The fixture provider is the default and needs no external API credentials. It creates
three fictional prospects representing an absent website, a social-only footprint, and a
weak website. One prospect is intentionally sent from Manager back to Communicator once,
proving that correction loops are versioned and visible.

```powershell
python -m pip install -e ".[dev]"
python scripts/migrate.py
python scripts/demo.py
uvicorn api.index:app --reload
```

Open `http://localhost:8000`, sign in with the development-only password
`fivefold-demo`, and choose **Finish fixture demo**. Production refuses to start without
an explicit password hash and non-development secrets.

Generate a password hash without printing the password itself:

```powershell
python scripts/hash_password.py
```

## Runtime architecture

- FastAPI and Jinja templates provide the dashboard and JSON API.
- SQLAlchemy targets SQLite for a zero-credential local demo and pooled Neon Postgres in
  deployed environments.
- The OpenAI Agents SDK creates exactly five `Agent` instances on live runs. Each uses
  `gpt-5.6-luna`, medium reasoning, a unique system prompt, and a Pydantic output schema.
- Google Places Text Search is used only by the live discovery adapter. It uses an
  explicit minimal field mask and does not persist raw reviews or raw Places responses.
- A Postgres-backed queue gives each stage an idempotency key, three transient retries,
  row-locked claiming, and resumability.
- Generated previews are 30-day, revocable bearer links with `noindex`, a restrictive
  CSP, disabled enquiry actions, and an immutable independent-concept disclosure.

## Required environment

Copy `.env.example` to `.env.local` and fill only local values. Never commit it.

| Name | Purpose |
| --- | --- |
| `DATABASE_URL` | Neon pooled Postgres URL; SQLite is allowed for local fixtures |
| `OPENAI_API_KEY` | Required for live five-agent execution |
| `OPENAI_MODEL` | Fixed to `gpt-5.6-luna` by default |
| `GOOGLE_MAPS_API_KEY` | Required only for live discovery |
| `ADMIN_PASSWORD_HASH` | PBKDF2 hash generated by the included script |
| `SESSION_SECRET` | Signs admin sessions and CSRF tokens |
| `CRON_SECRET` | Authenticates the Vercel worker cron |
| `PREVIEW_SIGNING_SECRET` | Reserved for preview-key rotation |
| `BASE_URL` | Canonical deployed URL used in communication drafts |

## Vercel and Neon bootstrap

The current workstation does not have the Vercel CLI installed, so linking and remote
resource creation are intentionally not performed by the repository scripts. Once the CLI
is available, use this order:

```powershell
vercel whoami
vercel link
vercel integration guide neon
vercel integration add neon
vercel env pull .env.local --yes
python scripts/migrate.py
vercel dev
```

Verify that all names in `.env.example` exist in Vercel before migration. The Neon
Marketplace integration should supply `DATABASE_URL`; all secrets should be configured for
development, preview, and production. `vercel.json` configures a one-minute authenticated
worker cron and a 300-second Python function duration.

Connect the GitHub repository to Vercel for preview deployments. The included GitHub
Actions workflow runs Ruff, mypy, schema creation, and the full fixture test suite.

## Safe operating boundary

- A human must independently verify contact details and manually send every message.
- Agents cannot send mail, post to social platforms, buy/associate domains, or publish an
  official client website.
- Review themes can influence design language, but testimonials remain labelled
  placeholders until the business supplies or approves them.
- `.ie` availability and price are estimates with a check time; no reservation occurs.
- External pages are untrusted data and never treated as agent instructions.
- At €14.99 cancel-anytime, early cancellation can lose money. The Manager reports the
  risk and cohort margin rather than presenting per-customer profit as guaranteed.

## API surface

Authenticated routes include research runs, prospects, retries, human statuses, audit
exports, preview revocation/redaction, and worker execution. `GET /preview/{token}` is the
only public prospect artefact. `GET /health`, `/privacy`, and `/terms` are public. There is
no communication or registrar mutation endpoint.
